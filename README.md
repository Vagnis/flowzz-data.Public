# CannaSync

## Beschreibung
CannaSync ist eine plattformübergreifende Daten-Anwendung. Das Projekt begann ursprünglich als Tool, das ausschließlich "flowzz" gescannt hat, und wurde mittlerweile um weitere Funktionen wie die Integration von "ansay" erweitert. Die grundlegende technische Software-Architektur des Projekts wurde im Juli 2026 erfolgreich finalisiert.


## Technologien & Architektur* 
**Programmiersprache & IDE:** Entwickelt in C# mit Visual Studio.


 * **KI-Features:** 
Die Architektur umfasst die Einbindung von benutzerdefinierten Modellen sowie generativen KI-API-Integrationen.


## Plattformen* 
**Aktuell:** Die Anwendung ist als Utility für Windows und Android verfügbar.

 * **In Planung:** Eine Portierung auf macOS und iOS ist vorgesehen, wobei die Code-Kompilierung auf einer Apple Silicon Mac-Plattform erfolgen soll.
